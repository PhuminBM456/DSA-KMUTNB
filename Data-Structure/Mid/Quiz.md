# Queue Service

โปรแกรมจัดการคิว (Queue) ที่รับคำสั่งทีละบรรทัด และรองรับ UNDO

## Input

| บรรทัด | รายละเอียด |
|--------|------------|
| 1 | จำนวนคำสั่งทั้งหมด n |
| 2 ถึง n+1 | คำสั่ง (หนึ่งคำสั่งต่อหนึ่งบรรทัด) |

## คำสั่ง

| คำสั่ง | การทำงาน |
|--------|----------|
| `ADD x` | เพิ่ม x ต่อท้ายคิว |
| `DISPLAY` | แสดงข้อมูลในคิว คั่นด้วย `,` ถ้าคิวว่างแสดง `EMPTY` |
| `ROTATE` | ย้ายตัวแรกไปท้ายสุด ถ้าคิวว่างไม่ต้องทำอะไร |
| `SERVE` | นำตัวแรกออกจากคิว |
| `TOP` | ดูตัวแรกสุด ถ้าคิวว่างแสดง `EMPTY` |
| `UNDO` | ยกเลิกการกระทำล่าสุด (ย้อนกลับ 1 step) ถ้าไม่มีคำสั่งก่อนหน้าแสดง `HISTORY CLEAR` |
| `EXIT` | จบโปรแกรม |

## Output

| กรณี | ผลลัพธ์ |
|------|---------|
| DISPLAY (มีข้อมูล) | ข้อมูลในคิวคั่นด้วย `,` เช่น `1,3,4` |
| DISPLAY (คิวว่าง) | `EMPTY` |
| TOP (มีข้อมูล) | ค่าตัวแรกสุดของคิว |
| TOP (คิวว่าง) | `EMPTY` |
| UNDO (ไม่มีประวัติ) | `HISTORY CLEAR` |

ทุกข้อความ output ขึ้นบรรทัดใหม่ (`\n`)

## ตัวอย่าง

Input:

```
14
ADD 1
ADD 3
ADD 4
DISPLAY
ROTATE
DISPLAY
SERVE
DISPLAY
UNDO
DISPLAY
UNDO
DISPLAY
UNDO
EXIT
```

Output:

```
1,3,4
3,4,1
4,1
3,4,1
1,3,4
HISTORY CLEAR
```
